# 缠论买卖点判定规则（B1 / B2 / B3 / S1 / S2 / S3）

本文件描述 `outputs/index.html` 里买卖点标注的**完整判定口径**，可直接拿数据复算。
所有规则都只使用 `chan.py` 已输出的笔（bi）与中枢（centers），**不引入任何 MACD / 背驰指标**。

对应实现：`work/build_bsp.py`（补算与落盘）、`work/verify_bsp.py`（不变量校验）、
`work/dump_example.py`（实例导出）。

---

## 1. 引擎现状：没有买卖点字段

`chan.py` 的 `_op_chan` 只返回 `klc / bi / segments / centers`；`tdx_eval.py` 只把它包装成
`CHAN*` 通道。**不存在** `buy_sell_points` / `bsp` / `B1` 之类的字段，也没有 MACD、面积、
力度、背驰任意一项输出。因此买卖点是本项目在快照之上**自行补算**的，口径如下。

补算方式：不重跑 `_op_chan`，而是对已有的 43,691 个逐根截断快照，在每个时点用当时的
笔/中枢重算一遍，再按「首次判定即冻结」写进压缩数据。

---

## 2. 输入字段

笔（紧凑形式，`build_snapshots.py` 的 `compact()` 产出）：

| 下标 | 含义 | 引擎原字段 |
|---|---|---|
| `r[0]` | 起点 K 线下标 | `fromKlu` |
| `r[1]` | 终点 K 线下标 | `toKlu` |
| `r[2]` | 方向，`+1` 向上 / `-1` 向下 | `dir` |
| `r[3]` | 起点价 | `beginVal` |
| `r[4]` | 终点价 | `endVal` |
| `r[5]` | 是否已确认，`1/0` | `confirmed` |

中枢：`c = [beginKlu, endKlu, zg, zd, lineCount, confirmed, ended, reason]`。

引擎配置（`tdx_eval._CHAN_CLV1`）：`bi_algo=clv1`、`bi_min_gap=3`、`bi_fx_check=skip`、
`bi_end_is_peak=false`、`bi_last_unconfirmed=true`、`include_seg_centers=false`。
其中 `bi_last_unconfirmed=true` 决定了「最后一笔即使未确认也会出现在快照里」，
这是买卖点能在 det 时被判出来的前提。

## 3. 力度定义（替代 MACD 面积）

```
strength(r) = |r[4] - r[3]| / max(1, r[1] - r[0])
```

单位是「价格 / 根」，即该笔的平均推进速度。**不是** MACD 面积，也**不是** MACD 柱面积/
黄白线回抽。选它是因为它只依赖笔的两个端点与根数，任何时点都能算、且不穿越未来。

---

## 4. 六类判据

记号：笔序列按起点升序为 `b[0..n-1]`；候选笔 `r = b[i]`；
`p  = b[i]` 之前最近一条同向笔（`hist[-1]`）；`p2 = hist[-2]`（再前一条同向笔）；
`prev = b[i-1]`；`nx = b[i+1]`。

### B1（一买，kind=0）

- **依赖**：同向笔 `p2`、`p`、候选笔 `r`（三者都向下），反向笔 `nx`（向上）。
- **成立条件**（全部满足）：
  1. `r`、`p`、`p2` 三条都是向下笔，且 `i+1 < n`（反向笔 `nx` 已存在）；
  2. **两连新低**：`p2[4] > p[4] > r[4]`（终点价逐级走低）；
  3. **力度衰减**：`strength(r) < strength(p)`（严格小于）；
  4. `nx[2] == +1`（反向笔方向正确）。
- **标记**：`x = r[1]`（第三段下跌的终点，即最低点所在 K 线），`price = r[4]`。
- **判定 K 线**：`nx`（反向向上笔）首次出现在快照里的那一根。在此之前 `nx` 不存在，
  条件 1 不成立，所以判不出来。
- **确认条件**：`r[5] == 1 且 nx[5] == 1` 时 `conf = 1`，否则 `conf = 0`（画虚线空心三角）。

### S1（一卖，kind=3）

与 B1 完全对称：

1. `r`、`p`、`p2` 都是向上笔，`nx` 向下且已存在；
2. **两连新高**：`p2[4] < p[4] < r[4]`；
3. **力度衰减**：`strength(r) < strength(p)`；
4. `nx[2] == -1`。
- 标记：`x = r[1]`（最高点），`price = r[4]`；确认：`r[5] && nx[5]`。

### B2（二买，kind=1）

- **依赖**：`a = b[i-2]`（B1 所在的下跌笔）、`b = b[i-1]`（第一段上冲）、
  `r = b[i]`（回调，向下）、`nx = b[i+1]`（第二段上冲，向上）。
- **成立条件**（全部满足）：
  1. `i >= 2`、`i+1 < n`；`b[i-2]` 已被判为 B1（即 `b1[i-2] == True`）；
  2. `r[2] == -1`，`b[i-1][2] == +1`，`nx[2] == +1`；
  3. **回调不破前低**：`r[4] > a[4]`（回调低点高于 B1 低点）；
  4. `b[4] > a[4]`（第一段上冲的高点高于 B1 低点）。**这条在结构上恒真**——
     向上笔从 `a` 的低点起笔必然收在其上方，保留只是为了条件完整。
- **标记**：`x = r[1]`（回调笔终点），`price = r[4]`。
- **判定 K 线**：`nx` 首次出现的那根。
- **确认条件**：`r[5] && b[5] && a[5] && nx[5]` 四笔都确认才 `conf = 1`。

### S2（二卖，kind=4）

对称：`b[i-2]` 已被判为 S1，`r[2] == +1` 且 `r[4] < a[4]`，`b[4] < a[4]`，
`nx[2] == -1`；确认条件同样是四笔全确认。

### B3（三买，kind=2）

- **依赖**：中枢 `c`（最近一个 `endKlu <= r[0]` 的中枢）、`prev = b[i-1]`（离开中枢的向上笔）、
  `r = b[i]`（回抽，向下）、`nx = b[i+1]`（向上）。
- **成立条件**（全部满足）：
  1. `1 <= i <= n-2`，`r[2] == -1`，`nx[2] == +1`；
  2. 存在中枢满足 `c.endKlu <= r[0]`；
  3. **间隔约束**：`r[0] - c.endKlu <= 40`（根）；
  4. **向上离开**：`prev[4] > c.zg`（离开笔收在中枢上沿之上）；
  5. **回抽不回中枢**：`r[4] > c.zg`（回抽低点仍在中枢上沿之上）。
- **标记**：`x = r[1]`（回抽笔终点），`price = r[4]`。
- **判定 K 线**：`nx` 首次出现的那根；若中枢是后补的（`nx` 已存在但中枢尚未出现），
  则顺延到中枢出现的那根。
- **确认条件**：`r[5] && prev[5] && nx[5] && c[5]`，笔与中枢都要确认。
- **注意**：判据**没有要求 `c.ended == 1`**，只要求 `c.endKlu <= r[0]`。
  这是一个已知的偏松点（见第 6 节）。

### S3（三卖，kind=5）

对称：`r[2] == +1` 且 `nx[2] == -1`，`prev[4] < c.zd`，`r[4] < c.zd`，
间隔同样 `<= 40` 根，确认条件同样含中枢。

## 5. 阈值来源与取舍

| 参数 | 取值 | 来源 / 理由 |
|---|---|---|
| `GAP` | 40 根 | 经验阈值：日线下约两个月，只把「刚离开不久的中枢」当作 B3/S3 的参照。超过 40 根视为该回抽与这个中枢无关，避免把很久以前的中枢拿来套。 |
| 力度比较 | 严格 `<` | 相等时不算衰减（宁可漏判，不做「不衰减也叫背驰」的宽松处理）。 |
| 「两连新低/新高」 | 严格不等式 | `p2[4] > p[4] > r[4]`，取等号不成立（平底/平顶不判）。 |
| `bi_min_gap` | 3 | 引擎配置，决定笔的最小根数，间接决定 strength 的分母下限。 |
| `bi_last_unconfirmed` | true | 决定未确认笔也进快照，故买卖点能在反向笔刚出现时（`conf=0`）先判出来。 |

## 6. 没有 MACD 时的替代与偏差方向

| 理论要求 | 本实现 | 偏差方向 |
|---|---|---|
| 一买/一卖要求**背驰**：MACD 面积缩小、或黄白线回抽零轴 | 用 `strength` 衰减替代 | **偏松**：只看「价格推进速度变慢」，不看动能面积，会把「跌得慢了但没背驰」也算成一买/一卖 → B1/S1 数量偏多。 |
| 段级别背驰（段与段比较） | 完全没有，只有笔级 | **漏判**：段级背驰成立的 1 买/1 卖判不出来；`strength` 只在同向相邻笔之间比较，跨段的力度关系无法表达。 |
| 二买/二卖（次级别回抽确认） | 纯结构（回调不破前低） | 基本无偏差：CL 理论中二买本就不强制要求背驰，结构判据与原意一致。 |
| 三买/三卖（次级别回抽不回中枢） | 纯结构（回抽不回 ZG/ZD） | 轻微**偏松**：未要求 `ended == 1`，会把仍在延伸的中枢当作参照；`GAP=40` 也允许中枢结束后较久才回抽。 |

一句话：**1 类（B1/S1）质量最弱、数量偏多；2/3 类（B2/S2/B3/S3）是纯结构判据，可信度更高。**

## 7. 不穿越未来与稳定性

- **冻结口径**：某时点首次算出的买卖点，其 `x / kind / price` 从此不变；
  只允许 `conf` 从 `0` 单向升级到 `1`；**从不删除**。
- **det**：记录「首次可判定的那根 K 线」（不是笔末端）。页面绘制时 `det > k` 一律跳过，
  所以任何时点看到的点都只用了该时点及之前的数据。
- 代价：`det` 普遍晚于 `x`（中位 7 根），图上标记落在笔末端，属于**回溯标注**，
  但在 `det` 之前它根本不存在，所以「事后回填」只体现在位置，不体现在时序。

### 7.1 x 与 det 的差距（1,241 个点实测）

| 区间 | 点数 | 占比 |
|---|---|---|
| det = x | 0 | 0% |
| 1 ~ 5 根 | 305 | 24.6% |
| 6 ~ 20 根 | 881 | 71.0% |
| 21 ~ 50 根 | 28 | 2.3% |
| 51 ~ 100 根 | 15 | 1.2% |
| 101 ~ 240 根 | 8 | 0.6% |
| > 240 根 | 4 | 0.3% |

中位 7 根、均值 10.6 根、P90 13 根、最大 407 根（399001 S3，1994-10-25 → 1996-06-25）。

其中 9 个点的 `det == k0`（回放起点）属于**预热边界**，不是判定延迟：
`x < k0` 时页面从 k0 才开始有快照，只能记成 k0。

两种画法的实际差异：

| 方案 | 点在图上出现的位置 | 移动量 | 价格与位置是否自洽 |
|---|---|---|---|
| A（当前默认） | 笔末端 `x` | 0 | 自洽：三角贴着结构极值的 K 线 |
| B（画在 `det`） | 判定时点 `det` | 全部 1,241 个点左→右移动；总 13,202 根；中位 7 根（240 档约 26px，480 档约 13px），最大 407 根（480 档约 744px） | 不自洽：结构价与 det 当日收盘价偏离中位 4.27%、P90 17.20%，最大 750% |

方案 B 的额外问题：77 个点与同标的其它点共用同一个 `det`（最多 3 个点挤在同一根 K 线），
标签会重叠；且三角所在高度仍是旧结构价，与脚下那根 K 线对不上。
极端偏离出现在 000002 的早期前复权数据（万科A 前复权价在 1990 年代接近 0 甚至为负），
不是判定错误。页面底部有「标记:笔末端 / 判定时点」开关，可现场切换对比。

## 8. 实例（可照数据复算）

### 例 1：600010 包钢股份 B1，x=2025-12-17，det=2025-12-30

det 时点的相关笔：

| 笔 | 区间 | 方向 | 端点价 | 根数 | strength | conf |
|---|---|---|---|---|---|---|
| `p2` | 2025-10-14 → 2025-10-31 | 下 | 3.07 → 2.54 | 13 | 0.04077 | 1 |
| `p`  | 2025-11-14 → 2025-11-28 | 下 | 2.68 → 2.38 | 10 | 0.03000 | 1 |
| `r`  | 2025-12-08 → 2025-12-17 | 下 | 2.47 → 2.30 | 7  | 0.02429 | 1 |
| `nx` | 2025-12-17 → 2025-12-29 | 上 | 2.30 → 2.43 | 8  | 0.01625 | 0 |

逐步核对：

1. 两连新低：`2.54 > 2.38 > 2.30` ✔
2. 力度衰减：`0.02429 < 0.03000` ✔（第三段跌得更慢）
3. 反向笔 `nx` 已存在且向上 ✔
4. → 判 B1，标记 `x=2025-12-17`，`price=2.30`
5. 确认状态：`r.conf=1` 但 `nx.conf=0` → 此刻 `conf=0`（虚线空心态）；
   等 `nx` 转确认后自动升级为 `conf=1`，位置与类型不变。

### 例 2：600010 包钢股份 B3，x=2025-08-15，det=2025-08-27

| 对象 | 区间 | 端点价 | conf | 说明 |
|---|---|---|---|---|
| 中枢 | 2025-04-21 → 2025-06-20 | ZG=1.82，ZD=1.73 | 0 | 5 笔构成，`ended=0` |
| `prev` | 2025-07-17 → 2025-07-30 | 1.97 → 2.92 | 1 | 向上离开 |
| `r`    | 2025-07-30 → 2025-08-15 | 2.92 → 2.47 | 1 | 回抽 |
| `nx`   | 2025-08-15 → 2025-08-25 | 2.47 → 2.99 | 0 | 再次向上 |

逐步核对：

1. `c.endKlu <= r[0]`：2025-06-20 ≤ 2025-07-30 ✔
2. 间隔：`r[0] - c.endKlu = 28 根 <= 40` ✔
3. 向上离开：`prev[4] = 2.92 > ZG = 1.82` ✔
4. 回抽不回中枢：`r[4] = 2.47 > ZG = 1.82` ✔
5. → 判 B3，`x=2025-08-15`，`price=2.47`
6. 确认：`nx.conf=0`、`c.conf=0` → 此刻 `conf=0`。

### 例 3：999999 上证指数 S1，x=2026-03-03，det=2026-03-10

| 笔 | 区间 | 方向 | 端点价 | 根数 | strength | conf |
|---|---|---|---|---|---|---|
| `p2` | 2025-11-24 → 2025-12-01 | 上 | 3816.58 → 3914.46 | 5 | 19.57600 | 1 |
| `p`  | 2025-12-16 → 2026-01-14 | 上 | 3815.84 → 4190.87 | 19 | 19.73842 | 1 |
| `r`  | 2026-02-03 → 2026-03-03 | 上 | 4002.78 → 4197.23 | 14 | 13.88929 | 1 |
| `nx` | 2026-03-03 → 2026-03-09 | 下 | 4197.23 → 4052.55 | 4  | 36.17000 | 0 |

1. 两连新高：`p2[4]=3914.46 < p[4]=4190.87 < r[4]=4197.23` ✔
2. 力度衰减：`strength(r)=13.88929 < strength(p)=19.73842` ✔
3. 反向笔 `nx` 向下且已存在 ✔
4. → 判 S1，`x=2026-03-03`，`price=4197.23`，`conf=0`（`nx` 未确认）。
