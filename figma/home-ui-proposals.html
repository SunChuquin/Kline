Kline 首页布局重设计方案 · 4 档

首页现状（A 档）只有标题栏 + 一句欢迎语，1024×768 的横屏画布几乎完全空置。真机验收后确认：旧首页把自选 / 行情 / 模拟做成快捷入口，与底部 Tab 完全重复，而且铺满首屏。 本次改版把入口压成一行可左右拖动的快捷入口（6 项，剔除与底部栏重复的三项），入口行下方留出四块内容区： 大盘概览条 / 我的自选 / 模拟账户汇总 / 涨幅榜。 A 档为现有实现的 1:1 复刻（基线，保持不变）， B / C / D 为三种新形态，分别用「卡片网格」「分区列表」「工作台混排」三种方式排布这四块内容。 所有画面按真机形态绘制（iPad 横屏 1024×768、涨红跌绿、底部四项 Tab：首页 / 自选 / 行情 / 模拟），屏内按钮与切换器均可点。 三档布局在「个人中心 → 首页布局」里独立选择，见区块二。

样机尺寸 1024×768（iPad mini 4 横屏） A 档 = 现有实现复刻（不变） B / C / D = 一行横滑入口 + 四块内容 默认档 B · 卡片网格 入口不再与底部 Tab 重复 示例数据，非真实行情
区块一

首页 · 4 档布局

现状（A 档）首页把自选 / 行情 / 模拟交易做成快捷入口，这三项与底部 Tab 完全重复，且宫格铺满首屏、把行情内容全挤到下一屏。 改版后 B / C / D 三档共用同一套结构：标题栏 → 一行横滑快捷入口（搜索标的 / 技术指标 / 选股指标 / 交易策略 / 条件单 / 个人中心，第 6 项半露示意可滑） → 四块内容区（大盘概览条 / 我的自选 / 模拟账户汇总 / 涨幅榜）→ 底部 Tab 栏。 三档只在这四块内容的排布方式上不同： B 卡片网格（通栏概览 + 2 列卡片 + 通栏涨幅榜）； C 分区列表（四块通栏卡、行高 24、信息密度最高）； D 工作台混排（大盘大卡 + 2 列小卡 + 底部横滑 chips）。四档共用同一批示例数据，仅渲染层不同。

方案信息密度横屏利用首屏信息量操作步数实现复杂度适配场景
homeA · 现有实现（保留）极低：整屏只有 2 行字浪费：内容居中、两侧与下方全空0 块内容 + 1 句欢迎语进任一功能 1 步（走底部 Tab）低：现有实现，零改动基线对照 / 保留老用户习惯
homeB · 卡片网格（默认档）高：1 行入口 + 4 块卡片，约 30 个数据元素好：入口行与通栏卡铺满 1024，第 6 张 chip 溢出表示可滑4 指数 + 家数 / 自选 5 行（带走势）/ 账户 4 项 / 涨幅榜 5 行1 步（横滑行直达；第 6 项需先横拖一次）中：横滑入口 + 3 种卡片高度 + 迷你走势默认档：既要入口，也要一眼看到行情
homeC · 分区列表最高：4 张通栏卡、19 行紧凑数据，行高仅 24最好：无 2 列分割，992pt 宽度全给数据列最多：19 行数据 + 4 指数 + 涨跌家数1 步（横滑行直达）低：4 张卡同一结构，行组件可复用信息优先：盯盘为主的老用户
