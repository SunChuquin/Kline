# Checklist

## 模型与持久化

- [ ] `SimCondKind` / `SimCondStatus` / `SimCondValidity` / `SimCondDirective` / `SimCondParams` / `SimCondRuntime` / `SimCondOrder` 全部实现为 `Codable, Hashable` 值类型，参数为扁平原生可选字段（无带载荷枚举）
- [ ] `sim.json` 根结构含 `conditionalOrders` 且 `schemaVersion = 2`；解码逐项兜底，旧的 schemaVersion 1 档案能无损读出六类既有数据
- [ ] 首次播种包含 3 张示例条件单（止盈止损 / 回落卖出 / 网格）
- [ ] 条件单创建后杀进程重启，列表内容与运行时进度与关闭前一致
- [ ] `SimStore` 所有条件单写入都走「值未变不写」守卫

## 评估与引擎

- [ ] `SimCondRule.evaluate` 为纯函数，不写任何数据、不触发落盘
- [ ] 判定三态齐全：`fire` / `hold` / `abort`，且 `abort` 携带可直接展示的中文原因
- [ ] 行情快照缺失（last 或 prevClose 为 nil）时判定为 `hold`，不误触发
- [ ] 止盈止损双边 OCO：先触发腿生效，另一腿随之失效
- [ ] 均线条件区分「首次穿越」与「持续满足」，后者不重复触发
- [ ] 触发后统一走 `SimStore.submit`，生成的 `SimOrder.originCondID` 指向条件单
- [ ] 单次触发类型下单被拒后置「已拒绝」且不重试；多触发类型失败保持「监控中」并记因
- [ ] `SimCondEngine.sweep` 有重入保护；`MarketRowCache.rows` 连续变化时只结算一次
- [ ] 一次结算只落盘一次（不是每张条件单各落一次盘）

## 有效期

- [ ] 当日有效条件单跨自然日后进入「已失效」
- [ ] 指定日期到期后进入「已失效」
- [ ] 长期有效不因时间失效
- [ ] 撤销后即便条件成立也不再生成委托

## 管理页

- [ ] 导航栏为 关闭 / 条件单 / 新建 三段结构
- [ ] 概览条展示 监控中 / 已触发 / 已失效 三段计数
- [ ] 分段切换互斥，切到「已触发」时不出现监控中与已失效的行
- [ ] 列表行含 标的名 + 代码、状态标签、类型 chip、条件摘要、委托指令摘要、有效期、行内操作
- [ ] 多触发类型行展示「N/M 档」进度与进度条
- [ ] 空态含引导文案与新建入口
- [ ] 底部常驻「行情刷新与手动检查时评估，非实时盯盘」提示与「立即检查」按钮
- [ ] 「立即检查」就地反馈本次结果（触发笔数 / 无触发），列表同步刷新

## 编辑器

- [ ] 结构完整：标的头卡 → 方向大分段 → 类型 chips（8 种）→ 类型参数卡 → 委托指令卡 → 有效性 → 预览摘要 → 提交
- [ ] 切换类型时方向 / 委托指令 / 有效性保持不变，仅类型参数重置
- [ ] 8 种类型的参数面板均可正常填写并提交成功
- [ ] 网格与分批能给出档位数 / 笔数分布预估
- [ ] 预览摘要为一句话自然语言，与提交后的列表摘要一致
- [ ] 非法参数（网格区间倒挂、数量非整手、缺行情等）被拦截并就地展示中文原因，不弹 alert
- [ ] 卖出方向止盈止损默认基准价为持仓成本价；无持仓时禁止保存并说明原因

## 入口

- [ ] 模拟页 A / B / C 三个布局工具栏都有「条件单」按钮，且带监控中数量角标
- [ ] 全屏下单页 `full` 形态的「条件单」入口带入当前方向 / 价格 / 数量
- [ ] 持仓表行内「条件单」按钮带入方向卖出、基准价成本价、数量可卖整手
- [ ] 入口按钮命中区不小于 44×44pt

## 记录与追溯

- [ ] `ActionModule.condition` 存在于操作日志类型筛选，且筛选后只出条件单记录
- [ ] 日志文案含标的 / 类型 / 触发结果，失败时含拒绝原因
- [ ] 条件单详情展示条件定义、委托指令、有效期、创建时间、触发记录
- [ ] 已触发条件单可跳转到其生成的委托

## 规范一致性

- [ ] 全部界面使用语义色，深色模式下无白底黑字残留
- [ ] 买入红 / 卖出绿与既有下单组件一致
- [ ] 未引入 Table / Chart / NavigationStack / `@Observable`，保持 iOS 15 兼容
- [ ] 新增主文件体积受控，纯展示原子件拆到 `SimCondKit.swift`

## 设备验证

- [ ] 阶段一真机验收通过（示例条件单可见 / 立即检查有结果 / 可触发并生成委托 / 可撤销）
- [ ] 阶段二真机验收通过（三处入口可用 / 8 种类型可创建 / 非法参数被拦截 / 深色模式正常）
- [ ] 阶段三真机验收通过（行情就绪自动结算 / 跨日失效 / 触发记录可追溯）
- [ ] 回归点确认：既有手动下单、撤单、改价、一键平仓、T+1 刷新行为未受影响
