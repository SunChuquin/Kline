# 境外 GitHub Actions runner 访问国内行情源被 502 拒绝（2026-09-22）

## 现象

云端定时产出分片的 workflow 反复失败，日志形如：

```
Run python3 src/live_db_builder.py --universe src/data/universe.txt --out dist --prev prev/live
[warn] 批量快照第 5/34 批失败: HTTP Error 502: Bad Gateway
```

job 在约 3m30s 后判失败（多批快照被拒，覆盖率不达标）。

## 根因

GitHub Actions 的 runner 在境外，访问国内行情源（`push2.eastmoney.com`）被网关/源站拒绝。
代码本身没问题——同一段 `live_db_builder.py` 在本机跑是通的（3312/3312、184 秒）。

## 现在的规避方式

云端定时方案**不采纳**（这条路线本身走不通，不是调参能救的）。改为：

- **设备侧直连东财**（设备在国内网络里，不需要 PC 也不需要 CI）；
- **PC 侧手动**差分/分片推送（需要电脑在场时）。

**遗留（未决）**：`Kline/.github/workflows/sync-live-db.yml` **仍在仓库里、未被删除也未被禁用**，
`cron` + `push` + `dispatch` 三种触发照旧，所以它会**按定时继续跑并继续失败**。
要么删掉、要么改成 `workflow_dispatch` 手动触发，属需用户拍板的清理项——留着不影响功能，但会让 Actions 页面一直有失败记录。
