# 刷新按钮优化计划

## 📋 任务概述
将自选页面的"刷新"图标按钮改为"刷新"图标+文字按钮（左图标右文字），样式参考旁边的搜索图标文字按钮，并在点击后显示对应的UI状态表示当前操作的进展。

## 🔍 当前状态分析

### 现有刷新按钮实现
- **位置**：`FavoritesPageKit.swift` 第599-614行
- **样式**：纯图标 `arrow.clockwise`
- **交互**：运行时显示 `ProgressView().scaleEffect(0.8)`
- **状态控制**：通过 `watchlistTappable` 控制禁用状态

### 搜索按钮样式参考（MarketToolButton）
- **位置**：`MarketPageKit.swift` 第614-636行
- **样式**：图标+文字组合
- **规格**：
  - 图标：12pt, medium权重
  - 文字：12pt, medium权重
  - 间距：5pt
  - 内边距：10pt水平
  - 外观高度：28pt
  - 背景色：systemGray6
  - 圆角：7pt
  - 命中区高度：44pt
  - 颜色：蓝色

### 进度显示实现参考
- **位置**：`FavoritesLayoutBView.swift` 第246-249行
- **数据源**：`model.refreshProgress` 包含 `(groupID: UUID, done: Int, total: Int)`
- **显示格式**：`Text("\(p.done)/\(p.total)")`
- **字体**：9.5pt, monospaced设计, secondary颜色

## 🎯 实现方案

### 1. 创建新的刷新按钮组件
**文件**：`FavoritesPageKit.swift`

**修改位置**：第599-614行的 `FavoritesToolbar` 中的刷新按钮

**实现逻辑**：
```swift
// 新的刷新按钮实现
Button {
    WatchlistSyncManager.shared.sync(reason: "手动")
} label: {
    HStack(spacing: 5) {
        if let p = model.refreshProgress {
            // 显示进度：图标 + 进度文字
            Image(systemName: "arrow.clockwise")
                .font(.system(size: 12, weight: .medium))
                .foregroundColor(.blue)
            Text("\(p.done)/\(p.total)")
                .font(.system(size: 12, weight: .medium))
                .foregroundColor(.blue)
        } else if watchlistSync.isRunning {
            // 显示加载中：图标 + 加载文字
            Image(systemName: "arrow.clockwise")
                .font(.system(size: 12, weight: .medium))
                .foregroundColor(.blue)
            Text("刷新中...")
                .font(.system(size: 12, weight: .medium))
                .foregroundColor(.blue)
        } else {
            // 正常状态：图标 + 刷新文字
            Image(systemName: "arrow.clockwise")
                .font(.system(size: 12, weight: .medium))
                .foregroundColor(.blue)
            Text("刷新")
                .font(.system(size: 12, weight: .medium))
                .foregroundColor(.blue)
        }
    }
    .foregroundColor(.blue)
    .padding(.horizontal, 10)
    .frame(height: 28)
    .background(Color(.systemGray6))
    .cornerRadius(7)
    .frame(minHeight: 44)
    .contentShape(Rectangle())
}
.disabled(!watchlistTappable)
.buttonStyle(.plain)
.fixedSize()
```
