# 填充淡化用「向白色混合」而非降低透明度（2026-09-19）

## 决策

四个环带的填充用**不透明色、向白色依次混合 50%**：`white` = 0 / 0.5 / 0.75 / 0.875。按钮整体的变淡（100% / 50% / 25%）只在最外层一处 `.opacity()` 施加。

## 为什么不直接用黑色 + 透明度递减

若填充写成 `黑色.opacity(1 / 0.5 / 0.25 / 0.125)`，同一个值就同时承载了「环带之间的层次」和「环带自身的深浅」两种语义，无法与整体透明度解耦；而且 100% 全不透明的标准态就没有基准形态可对照。

## 配套前提

整体透明度**必须先经 `.compositingGroup()` 合成再施加**，否则重叠子视图会被逐层叠加 —— 见 [[20260919-重叠子视图的透明度被逐层叠加]]。
