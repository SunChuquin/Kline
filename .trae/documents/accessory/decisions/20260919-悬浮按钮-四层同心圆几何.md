# 四层同心圆的几何推导（2026-09-19）

## 需求给出的两个约束

1. A 直径 = D 直径 × 2
2. Z 环宽 = X 环宽 + Q 环宽

## 推导

设半径为 A_r / B_r / C_r / D_r。约束 2 展开：

```
(A_r − B_r) = (B_r − C_r) + (C_r − D_r) = B_r − D_r
→ B_r = (A_r + D_r) / 2
```

**B 被唯一确定，且与 C 无关。** 约束 1 定出 `D_r = A_r / 2`。以 A 直径 56（沿用原按钮宽度）计：

| 圈 | 半径 | 直径 |
| --- | --- | --- |
| A | 28 | 56 |
| B | 21 | 42 |
| C | 17.5 | 35 |
| D | 14 | 28 |

环宽：Z = 7、X = 3.5、Q = 3.5（X + Q = 7 = Z ✓）

## C 为什么是「取值」而非「推导」

约束 2 右侧的 C 自己消掉了（`X + Q` 恒等于 `B_r − D_r`），**该式对 C 无约束**。补了一条最小假设「X 与 Q 等宽」→ `C_r = (B_r + D_r) / 2`。想让 X ≠ Q，只改 `radiusRatios` 第三项，且须保持 X + Q = B_r − D_r（即 C 在 B、D 之间任取）。
