# 联动多图模式下光标自动移动时隐藏两个悬浮按钮（2026-09-19）

> **已由用户真机确认**（2026-09-19）：自动移动期间两个按钮一起隐藏、停止后恢复。
> （该行为一开始被"主格被冻结"掩盖 —— 冻结修好后才显现，见 [[20260919-主格永不冻结]]。）

## 决策

**联动多图模式**下光标自动移动期间（贴边自动滚动、**抬手后仍在继续**），两个悬浮按钮一起淡出并关闭命中；
自动移动结束即淡入恢复。

## 三个非显然的处理

1. **「联动多图模式」由 `isLinkedTile` 精确表达**：该参数只有 `LinkedKlineTile` 传 `true`，单图路径默认 `false`。
   上报里 `guard isLinkedTile`，所以单图模式的自动滚动**不会**隐藏按钮 —— 与需求限定的范围一致。
2. **两个按钮各自订阅、各自隐藏**，而不是让 `ContentView` 观察协调对象：
   协调对象上还有转圈每根推进、每次点击等**高频发布**，根视图一观察就会连累 `MarketView`/`FavoritesView`
   整树重算。藏在按钮自己是零成本的。
3. **`stopEdgeAutoScroll` 首行无条件复位标志**（不做条件判断）：一旦因任何异常路径把标志留在 `true`，
   两个按钮会被**永久隐藏**，这是不可接受的失败模式，所以这里刻意不用幂等守卫。

## 上报点（三处，覆盖全部结束路径）

| 时机 | 位置 |
| --- | --- |
| 自动滚动启动成功 | `startEdgeAutoScroll` 尾部（`animator.start()` 之前） |
| 被主动终止（光标被清除 / 手指退回内侧 / 双指接管 / 视图销毁 / 数据刷新） | `stopEdgeAutoScroll` 首行 |
| 走到数据边界自然停 | `animator.onFinish`（它不经过 `stopEdgeAutoScroll`） |

视图销毁走 `KlineChartView.onDisappear` 里的 `stopEdgeAutoScroll()`，已被第 2 行覆盖。
