# B' 被操作期间整体换成旧按钮外观（2026-09-19）

## 决策

点击 / 摁着 / 拖着新按钮的 **B'**（整钮模式）时，整个按钮临时呈现**旧按钮拖动状态的外观**
（四层同心圆 A/B/C/D，`FloatingAccessoryRings()`）；**静止 0.5 秒后**还原成新按钮自身的稳定态（三圆 A'/B'/C' + 闲置淡出）。

> 时长口径：**新按钮的闲置时长是 0.5 秒**（`FloatingAccessoryMetrics.wheelIdleFadeDelay`），
> 旧按钮仍是 3 秒（`idleFadeDelay`）。两者不共用同一个常量。

## 关键实现点

1. **外观切换与「0.5 秒」共用一个时刻**：还原不另起计时器，而是挂在既有 `scheduleIdleFade` 的 0.5 秒计时里
   （`isDimmed = true` 与 `showsOldLook = false` 同一个 `withAnimation` 事务）。
   于是「临时外观」恰好等于既有的「触碰后保持 100% 三秒」窗口 —— 两者本来就是这个控件的同一条时间线。
2. **尺寸取旧按钮原尺寸 56pt**（`FloatingAccessoryRings()` 默认直径），居中于 A' 盘心。
   想改成「图案换成四环但仍撑满 128.8」只需传 `diameter: FloatingAccessoryMetrics.wheelOuterDiameter`。
3. **外层 frame 恒取 A' 直径 128.8**：命中区不随外观切换而缩小，56pt 图形居中后盘心不变，
   落点半径判定与 `atan2` 的圆心口径完全不受影响。
4. **环上转圈不触发旧外观**（`showsOldLook = (mode == .whole)`）：旧外观里没有 C'，
   若转圈时也切过去就看不到任何转圈反馈。

## 陷阱：`forceIdle` 必须一并还原

`forceIdle()` 里那句 `idleFadeToken += 1` 是为了作废在途淡出计时，但它**同时会作废那个「0.5 秒后还原旧外观」的计时**
（两者共用一个令牌）。所以 `forceIdle` 里必须显式 `showsOldLook = false`，
否则「B' 操作完 → 0.5 秒内碰到另一个按钮」这一条路径会让旧按钮外观**永久留在屏幕上**。
