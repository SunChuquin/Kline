# 重叠子视图的透明度被逐层叠加（2026-09-19）

## 现象

四层同心圆的层次在 100% 透明度时正确（外深内淡），但 50%（摁住）与 25%（闲置淡出）两态下 **X 环带比 Z 更深**。

## 根因

`.opacity()` 作用在由**相互重叠**的子视图组成的容器上时，SwiftUI 默认**逐层施加、不做离屏合成**，
让各子层彼此做半透明混合。四圈层层覆盖，于是各环带经历的混合次数不同：

| 环带 | 被叠加的半透明层数 |
| --- | --- |
| Z | 1（只圆 A） |
| X | 2（A + B） |
| Q | 3 |
| W | 4 |

浅色模式白底、α=0.25 时逐层算得的合成白度：

```
Z = 0.750
X = 0.688   ← 反而最深
Q = 0.703
W = 0.746
```

α=1 时看不出异常：四层填充都是不透明色，覆盖后只留最上面一层，叠加次数不影响结果。
**「只在半透明态暴露」正是这个坑的识别特征。**

## 现在的规避方式

在 `.opacity()` **之前**插入 `.compositingGroup()`：先把四圈合成为单一离屏图层，
再整体乘透明度，使 100% / 50% / 25% 三态的深浅顺序完全一致（等比整体变淡）。
