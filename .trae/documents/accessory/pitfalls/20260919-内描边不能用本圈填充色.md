# 内描边不能用本圈填充色（2026-09-19）

## 现象

若把四圈的描边色写成「与本圈 `fill` 同色」，描边**完全看不见**。

## 根因

`strokeBorder` 是**内描边**：整条描边落在该圆自身的填充范围内，同色即被自身填充吞掉。
只有最外圈 A 的描边有一部分压在页面上才有意义，内圈 B / C / D 全都无效。

## 现在的规避方式

描边统一用**语义色 `Color(.label)`**（浅色模式=黑、深色模式=白），
靠 `ringStrokeOpacities` 逐圈降低浓度（1 / 0.5 / 0.25 / 0.125）来实现需求里「同样淡 50%」的节奏。

语义色还顺带解决另一个问题：深色模式下最外圈 Z 是纯黑，会与深色背景糊在一起，
白描边正是用来勾出外轮廓的 —— 所以 A 圈的描边浓度保持 1.0 不削弱。

- `Kline/App/FloatingAccessory.swift:67-75`（`ringStroke` / `ringStrokeWidth` / `ringStrokeOpacities`）
- `Kline/App/FloatingAccessory.swift:108-109`（`strokeBorder` 调用点）
